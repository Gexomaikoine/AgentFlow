# AgentFlow 发布产物

本仓库只存放 AgentFlow 的发布产物，**不含源码**。请勿在此提交其他内容。

## 新用户：安装

1. 下载本仓库里版本号最新的 `AgentFlow-Setup-<版本>.exe`（约 69 MB）
2. 双击运行 —— 安装是**当前用户级**的，不需要管理员权限
3. 装完会自动打开控制台，按首次配置向导填入模型 API Key 即可开工

> **运行安装包时提示「Windows 已保护你的电脑」？**
> 安装包未做代码签名，这是预期现象。点「更多信息」→「仍要运行」即可。

安装目录默认在 `%LOCALAPPDATA%\AgentFlow`，开始菜单里会有「AgentFlow 控制台」与「卸载 AgentFlow」。

## 已装用户：更新

**不需要手动操作。** 程序启动后会自行检查更新；有新版时控制台顶栏会出现「⬆ 有新版本」，
点一下即可完成升级（只替换程序文件，你的配置、API Key、数据库与历史记录都不会被动）。

若更新页签提示「需重装安装包」，说明该版本调整了内置依赖，请下载新版安装包覆盖安装一次。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `AgentFlow-Setup-<版本>.exe` | 安装包 —— **新用户下载这个** |
| `app-<版本>.zip` | 增量更新包 —— 程序自动使用，无需手动下载 |
| `manifest.json` | 更新清单 —— 程序自动读取，用于判断是否有新版本 |

## 卸载

从开始菜单运行「卸载 AgentFlow」，或到「设置 → 应用」里卸载。

卸载**不会删除**你的数据目录 `%USERPROFILE%\.agentflow`（配置、密钥、数据库、历史记录都在那里），
需要彻底清理时请手动删除该目录。
